So, if you run ls, it will not display hidden files by default. In order to see hidden files, you need to use the -a option to ls. If we wanna see a long listing output that includes hidden files, we could run ls -l -a. There's also kind of a shortcut for this. It doesn't matter which order that we specify these command line arguments in; I mean, -a -l does the same thing as -l -a. When you perform an ls by itself, you may or may not know what is a file and what is a directory. You can use ls -F to reveal file types. ls -F appends a character to a file or directory name that tells you what it is. So, if it ends in a slash, or a forward slash, then it's a directory. If it ends in an at sign, it's a link. A star, or an asterisk, means that it's executable. You can think of a symbolic link as a pointer. It looks like a file or a directory, but it just points to where the actual file or directory is. And you would operate on the symbolic link, or symlink for short, the same as if it were the file that it's pointing to. Symlinks are often used to create shortcuts to long file names or long directory paths. Another common use of symlinks is to indicate the current version of an application. And we can confirm by running ls -lF for a long listing format, and we see current points to my-app-2.4.7. Here we see a program; it's an executable 'cause it ends in an asterisk or a star. And we can execute this by doing ./myapp. If you wanna list files sorted by time, use ls -t. Use the -r option to reverse the order. And a common command that I like to use is ls -latr. To list directory contents recursively, use ls -R. This will display all the contents of the current directory and any subdirectories below that. The tree command does a similar thing to ls -R, but it's more of a visual output. You can give tree a -d option, and that will only list directories. And if you use a -C, that will colorize the output. Tree is on a lot of Linux distributions. It may not be installed by default, so you may or may not have access to this command. Like the tree command, ls has a -d option that only lists directory names and not their contents. By default, when you run ls directory-name, ls will provide the contents of that directory. You can also tell ls to colorize output by using ls --color. This is just another option to distinguish file types. You can do ls -F, or ls --color, or even combine the two. You can use --color for ls to get color output, and sometimes this is done by default on some Linux distributions. And the color coding here, like in this configuration, blue are directories. Instead, get in the habit of using maybe a hyphen or a dash where you would use a space, or maybe an underscore, or even something called camel case, where you can capitalize the first letter of each word. Sooner or later, you're going to encounter a file name that has a space in it. It may be a file that you didn't create and someone else did. You have no control over that. How you can deal with this is wrapping the file name in quotes, be it single quotes or double quotes. Another thing you can do is escape the space character.
