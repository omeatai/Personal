In today's lesson, we'll be learning how to use the emacs editor. Emacs like vi is a powerful editor. Some people prefer vi, others prefer emacs. My recommendation to you is to experiment with the emacs editor and the vi editor and see which one you feel more comfortable with. You can't make a bad choice. To edit a file with emacs, run emacs and provid it the filename that you wish to edit. When you look at the emacs documentation, you'll see 'c-' character. This means to hold down the control key while pressing that character. For example, 'c-h' means to hold down the control key while pressing the 'h' key. If you see 'c-h t', that means to hold down the control key while pressing the 'h' key, release the control key and then type the letter 't'. When you see 'm-' character, that means to hold down the meta key. The meta key is the 'alt' key. You can also substitute the 'esc' key for the 'alt' key. For example, 'm-f' translates to holding down the alt key and pressing 'f', or pressing and releasing 'esc', followed by the 'f' key. You may need to use the 'esc' key as the meta key since 'alt' can sometimes be intercepted by your terminal program for instance. If you want to simplify things, just always use the 'esc' key for the meta key. Use 'ctrl-h' to get help. Type 'ctrl-x' followed by 'ctrl-c' to exit emacs. 'ctrl-x ctrl-s' saves the file, and 'ctrl-h t' will start the built-in tutorial. 'ctrl-h k' followed by a key will describe that key. You can use this to get help on a specific key command or key combination. 'ctrl-p' will take you to the previous line, while 'ctrl-n' will take you to the next line. 'ctrl-b' is to go backward one character, 'ctrl-f' is to go forward one character. 'M-f' will move you forward one word and 'M-b' will take you back one word. 'ctrl-a' will take you to the beginning of the line, 'ctrl-e' will take you to the end of a line. 'M-<' will take you to the beginning of the file and 'M-' followed by the '>' symbol will take you to the end of the file. To delete a character, type 'ctrl-d', to delete a word, its 'M-d'. 'ctrl-k' will kill the rest of the current line. To kill the entire line, just position the cursor at the beginning of the line and type 'ctrl-k'. In vi, yank means to copy, in emacs, yank means to paste. So 'ctrl-y' is to yank or paste from the previously killed text. To undo, type 'ctrl-x u' 'ctrl-s' will start a forward search. Type the text you're looking for, and type 'ctrl-s' again to move to the next occurrence of that text. Press enter when you're done searching. 'ctrl-r' starts a reverse search. Like vi, emacs provides a way to repeat commands. For instance to kill 3 lines of text, type 'ctrl- u 3 ctrl-k'. Let's edit a file with emacs to file.txt. To navigate, you can use 'ctrl-n' to go the next line. And 'ctrl-f' will go forward one character. 'ctrl-p' will go previous line. 'ctrl-b' will go back a character. To get to the beginning of the line, type 'ctrl-a', and to the end, 'ctrl-e'. And you can just start typing text wherever your cursor is. Let's delete a character with 'ctrl-d'. To delete a word, type 'M-d'. Can I use 'alt-d'? Or 'esc-d'. Let's kill a line of text with 'ctrl-k'. And I'll move to the bottom of the file and yank it or paste it in. Let's start a search. Let's search for 'the'. 'ctrl-s' will take you to the next occurrence and then when you're done, you can just hit enter. And if we do a reverse search, we can do that with 'ctrl-r'. Let's do the same thing. 'ctrl-r' takes you to the previous one and when you're done, you can hit enter. To exit, 'ctrl-x ctrl-c'. And I'm not going to save my changes. Let's get back to emacs again. And we can save the file with 'ctrl-x ctrl-s'. Again to exit, 'ctrl-x ctrl-c'. Emacs is a more powerful editor than nano. Emacs is also an alternative for vi. Again some people prefer vi, others prefer emacs. I suggest you try them both and see which you feel comfortable with.
