Instructor: In this lesson, you'll learn what the shell is, how to access it, and we'll talk a little bit about the superuser account. The shell is the default user interface to a Linux system. When you log into a Linux system over the network, the shell is the program that starts and acts as your default interface to the system. If you're presented with a text-based login prompt, you'll also be interacting with a shell by default. If you log into a graphical user interface, then you'll need to start a terminal emulator application to gain access to the shell. In AlmaLinux, for example, you can go to the activities menu, then type terminal and click on it to start it. It's the same for Ubuntu, just click on activities in the top left corner of the screen and start a typing terminal. Once you see the terminal application, click on it to start it. You could also press enter when the terminal application is highlighted to start it. The graphical user interface on a Linux system is also called a shell, but it's a graphical shell. However, if someone isn't specific and they say shell, they're typically talking about the command line interface. The shell is nothing more than an application or program that takes the commands you send to it and executes those commands for you. Sometimes you'll hear the shell referred to as a command line interpreter. The command line interface can be more powerful than the graphical interface. For example, if you have several files and you need to perform the same operation on all of those files, you can often do this easily at the shell. If you had 100 documents that you needed to rename, you could run a command at the shell to do all 100 at once. However, if you're using the graphical user interface, you would have to click on the first file, rename it, click on the next file, rename that one, and repeat that process 98 more times. In this instance, the command line is a much better solution. Another reason you want to be familiar with a command line and be able to use it effectively is that it's always going to be there. Most server editions of Linux distributions do not include a graphical interface. Also, when you're connecting to a Linux system over the network, you're typically going to be connecting via SSH or Secure Shell, which gives you access to the command line interface as well. Desktop Linux distributions have both graphical user interfaces and command line interfaces, allowing you to have the best of both worlds. When it makes sense to use the command line, we'll go ahead and use it, and when it makes sense to use a graphical program, then use that program. For example, if I was working on a Linux desktop and wanted to visit Wikipedia on the web, I would start a graphical web browser like Firefox. Now, there are command line web browsers that come with Linux, so you can surf the web from the command line. One of those is called Lynx, spelled L-Y-N-X. You can use Lynx to browse to any page you want, but the experience is not the same as it would be in a modern graphical web browser. Given the choice of using command line for web browsing or a graphical web browser such as Firefox, well, I would choose Firefox. When the shell is started, it displays a prompt or a shell prompt. The prompt simply sits there and waits for you to do something interesting like give it a command to execute. A shell prompt typically gives you some sort of useful information. In this example prompt, you'll see a username, which is Jason, followed by an at symbol and the name of the Linux system that you're connected to., in this case, linuxsvr, or Linux server. At the end of the prompt, you'll see a dollar sign, which is an indication that you're using the system as a normal user as opposed to a superuser. The superuser shell prompt typically ends with a pound sign. The superuser on a Linux system is also called root, as it is the root account. We previously talked about the root of the file system or slash being root, but this is a different root. This is an account called root, so when someone talks about root, they're either talking about slash, which is the beginning of the file system, or the superuser account named root. Obviously, you'll know which one given the context. The root account on a Linux system is similar to an administrator account on a Windows system. Anything that can be done on a Linux system can be done by the root user. Normal user accounts can only do a subset of the things that the root account can do. Most of your day-to-day activities will be performed with a normal user account. Root access is typically restricted to system administrators. For example, if you're working in a company and you have access to Linux servers, there will be a team of people that are responsible for the upkeep, maintenance, and configuration of those servers, and those people are the system administrators. Sometimes, there are not dedicated people who are system administrators. For example, if you're running Linux on your desktop, you'll have access to a normal user account and the root account as well. You may need root access if you're going to install an application that resides outside of your home directory. You may also need root access in order to start or stop that application. Applications that run as services or servers typically need root access to start or stop. For example, you need root access in order to start a web server. However, you don't need special privileges to start normal applications, like a web browser, for example. Prompts can vary greatly in appearance. Sometimes they're very simple. They're only one character in length, like a dollar sign. Sometimes they contain more useful information, such as the account you're using, the name of the server that you're connected to, and the directory that you're currently in. In a couple of these prompts here on your screen, you'll notice a tilde. The tilde is a shorthand way of representing a home directory. The tilde used by itself represents your home directory or the current account's home directory that you're using. For example, if I'm logged into a Linux system with a Jason account, tilde represents /home/jason. You can also append a username to the tilde, and that will expand to that account's home directory. For example, tilde pat could expand to /home/pat. Root's home directory is typically /root, so tilde root equals /root. Not all accounts on a Linux system are associated with an individual user. For example, services often have their own accounts. In this case, tilde ftp expands to the home directory of the FTP service account, which lives in /var/ftp. So far, we've looked at prompts that are contained within a single line. Just know that they can span multiple lines as well. Later in this course, you'll learn how to customize the shell prompt to your liking. In summary, the shell is the default user interface for Linux systems. You're automatically presented with a shell prompt if you connect to Linux over the network using SSH. If you log into a graphical user environment, you can start the terminal application to gain access to the command line. Shell prompts are symbols or text that appear on the command line interface. The appearance of shell prompts can vary greatly depending on the system, the configuration, and personal preferences. Root is a special user on a Linux system. It's the all-powerful superuser. Your day-to-day activities will be performed using your regular user account, while system administration tasks will be performed using the root account.
