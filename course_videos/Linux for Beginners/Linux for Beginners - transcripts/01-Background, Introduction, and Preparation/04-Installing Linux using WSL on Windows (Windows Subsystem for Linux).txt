WSL stands for Windows Subsystem for Linux, and it's a Windows feature that allows you to run Linux without the need for virtual machines or dual booting. Also, you're not limited to a single Linux distribution as WSL allows you to run multiple Linux distros if you so desire. Finally, WSL consumes less resources than virtual machines. In order to install WSL, you need to be running Windows 10 or newer. Also, you'll need to have virtualization enabled in your computer's BIOS settings. If you see a message from WSL asking you to enable virtualization in your BIOS, then you need to boot your computer into the BIOS and enable virtualization. Now, exactly how to do this varies from manufacturer to manufacturer, so you might have to look up the documentation for your specific computer and hardware. Finally, you need a working internet connection so you can download Linux. There are several Linux distributions supported by WSL, including Ubuntu, AlmaLinux, Debian, Kali Linux, Oracle Linux, and SUSE to name a few.
