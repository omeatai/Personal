## [COURSE](https://www.youtube.com/watch?v=avg65oY7sj4)

## Introduction

This is the full command-line series in one video, recorded on **Linux Mint MATE**. A command is the program name, optional options that usually start with a dash, and an argument such as a file or directory. The same commands work on Red Hat, Ubuntu, and Arch, and on other Unix-family systems, with small differences. A server often has no graphical desktop, so the terminal is the whole interface. The series starts with `echo` and `ls`, then files, users, permissions, text tools, archives, scheduling, processes, tmux, disks, LVM, ZFS, and LUKS.

Use this file as the table of contents. Open a chapter when you are ready to study that part of the video.
