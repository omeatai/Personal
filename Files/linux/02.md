# Linux Security & Administration From Boot Process to Firewalls

## [COURSE](https://www.youtube.com/watch?v=_WB3evmgxYA)

## Introduction

This course hardens a Linux system from the boot path to the firewall. Linux here means the kernel. A distribution adds a desktop, GNU tools, and other packages. The lessons use CentOS as a binary match for Red Hat Enterprise Linux, plus Ubuntu and Kali. A hardened server often has no graphical desktop, so the work is done in the terminal. Debian-family systems use `apt-get`. Red Hat-family systems use `yum`. The path is distributions, the boot process, services, logging, intrusion detection, users and permissions, administration tools, the kernel, then firewalls.

Use this file as the table of contents. Open a chapter when you are ready to study that part of the video.
