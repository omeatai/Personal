JS Mistakes

Open each example:

  • 01 — if (x == 10) is false when x is 0
  • 02 — if (x = 10) is true — assignment, not comparison
  • 03 — if (x = 0) is false — 0 is falsy
  • 04 — 10 == "10" is true (loose comparison)
  • 05 — 10 === "10" is false (strict comparison)
  • 06 — switch(x) case 10 matches number 10
  • 07 — switch(x) case "10" does not match number 10
  • 08 — 10 + 5 is 15; 10 += "5" is "105"
  • 09 — x + y is 15 or "105" depending on y's type
  • 10 — 0.1 + 0.2 is not 0.3
  • 11 — (x * 10 + y * 10) / 10 is 0.3
  • 12 — You may break a statement after = across two lines
  • 13 — Breaking in the middle of a string is a SyntaxError
  • 14 — Backslash continues a string across lines
  • 15 — if (x == 19);{ } always runs the block
  • 16 — return a * power works without semicolons (ASI)
  • 17 — return a * power with semicolons — same result
  • 18 — You may break after `return a *` onto the next line
  • 19 — Never break after return — it becomes return;
  • 20 — ASI reads that as return; a * power;
  • 21 — Arrays use numbered indexes — length 3, person[0] is John
  • 22 — person["firstName"] turns the array into a plain object
  • 23 — Trailing commas in objects/arrays are legal in ES5
  • 24 — JSON.parse rejects trailing commas
  • 25 — if (typeof myObj === "undefined") is safe
  • 26 — Test typeof !== undefined before !== null
