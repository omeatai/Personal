JS Error Object

Open each example:

  • 01 — new Error() — creates an Error object
  • 02 — name — sets or returns the error name
  • 03 — message — sets or returns the error message
  • 04 — cause — sets or returns an error cause
  • 05 — Error.isError(x) — true only for real Error objects
  • 06 — EvalError — deprecated name; use SyntaxError
  • 07 — RangeError — a number out of range
  • 08 — ReferenceError — an illegal reference
  • 09 — SyntaxError — eval of invalid source
  • 10 — TypeError — wrong type for the operation
  • 11 — URIError — decodeURI / encodeURI malformed
