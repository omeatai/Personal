JS Best Practices

Open each example:

  • 01 — Avoid global variables — they can be overwritten
  • 02 — Always declare local variables (var / let / const)
  • 03 — Put all declarations at the top of the script or function
  • 04 — Initialize variables when you declare them
  • 05 — var carName = "Volvo"; var carName; keeps the value (not recommended)
  • 06 — let carName twice — SyntaxError
  • 07 — const carName twice — SyntaxError
  • 08 — let car = {...}; car = "Fiat" changes the type
  • 09 — const car = {...}; car = "Fiat" is not possible
  • 10 — let cars = [...]; cars = 3 changes array to number
  • 11 — const cars = [...]; cars = 3 is not possible
  • 12 — Don't use new Object() — use literals
  • 13 — let x = "Hello"; x = 5 changes typeof to number
  • 14 — 5 + 7 is 12; 5 + "7" is "57"; 5 - "7" is -2
  • 15 — "Hello" - "Dolly" returns NaN
  • 16 — Use === — 0 == "" is true; 0 === "" is false
  • 17 — Default a missing argument: if (y === undefined) y = 0
  • 18 — ES2015 default parameters: function (a = 1, b = 1)
  • 19 — Always end switch with default
  • 20 — "John" === new String("John") is false
  • 21 — new String("John") == new String("John") is false
  • 22 — Avoid eval() — it runs text as code
