Debug Reference

Open each example:

  • 01 — assert() — logs only when the assertion is false
  • 02 — clear() — clears the console
  • 03 — dir() — interactive listing of object properties
  • 04 — count() — how many times this call ran
  • 05 — error() — error-styled console message
  • 06 — group() — indent following messages until groupEnd()
  • 07 — groupCollapsed() — same group, starts collapsed
  • 08 — groupEnd() — exits the current inline group
  • 09 — info() — informational console message
  • 10 — log() — general message; accepts multiple arguments
  • 11 — table() — tabular data as a table
  • 12 — time() — starts a named timer
  • 13 — timeEnd() — stops a timer started by time()
  • 14 — trace() — stack trace to the console
  • 15 — warn() — warning-styled message (often yellow)
