<details id="question-1-support-plans-that-open-requests">
<summary><strong>Question 1 - Support plans that open requests</strong></summary>

DRAG DROP

Your company intends to subscribe to an Azure support plan.

The support plan must allow for new support requests to be opened.

Which of the following are support plans that will allow this? Drag the correct options from the list into the answer area.

![Support plan options with an empty answer area](figures/question-01-options.png)

_Figure: Options are Basic, Developer, Standard, Professional Direct, and Premier. The answer area is empty._

</details>

<details id="answer-1">
<summary><strong>Answer 1</strong></summary>

Basic, Developer, Standard, and Professional Direct. Premier stays in the options list.

![Support plans placed in the answer area](figures/question-01-answer.png)

_Figure: Basic, Developer, Standard, and Professional Direct are in the answer area. Premier is not._

Basic can open billing and subscription support requests. Developer, Standard, and Professional Direct can open technical support requests. Premier is not one of the plans this question places in the answer area.

</details>

<details id="question-2-storage-readable-in-two-regions">
<summary><strong>Question 2 - Storage readable in two regions</strong></summary>

Your company has datacenters in Los Angeles and New York. The company has a Microsoft Azure subscription.

You are configuring the two datacenters as geo-clustered sites for site resiliency.

You need to recommend an Azure storage redundancy option.

You have the following data storage requirements:

- Data must be stored on multiple nodes.
- Data must be stored on nodes in separate geographic locations.
- Data can be read from the secondary location as well as from the primary location.

Which of the following Azure storage redundancy options should you recommend?

- A. Geo-redundant storage
- B. Read-only geo-redundant storage
- C. Zone-redundant storage
- D. Locally redundant storage

</details>

<details id="answer-2">
<summary><strong>Answer 2</strong></summary>

B. Read-only geo-redundant storage.

Geo-redundant storage keeps a copy in a paired region, but that copy is not readable until Microsoft fails the account over. Read-only geo-redundant storage (RA-GRS) is the same copy plus read access to the secondary. Zone-redundant storage stays in one region. Locally redundant storage stays in one datacenter.

</details>

<details id="question-3-cheapest-plan-for-a-design-assessment">
<summary><strong>Question 3 - Cheapest plan for a design assessment</strong></summary>

This item shares its setup with other questions. Each one proposes a different solution. Decide whether this solution meets the goal.

Your company's Azure subscription includes a Basic support plan.

They would like to request an assessment of an Azure environment's design from Microsoft. This is not supported by the existing plan.

You want the company to subscribe to a support plan that allows this, while keeping expenses to a minimum.

Solution: You recommend that the company subscribes to the Professional Direct support plan.

Does the solution meet the goal?

- A. Yes
- B. No

</details>

<details id="answer-3">
<summary><strong>Answer 3</strong></summary>

B. No.

The goal is a design assessment at the lowest cost. Developer and Standard both include general architecture guidance, and both cost less than Professional Direct. Professional Direct can cover a deeper review, but it does not keep expenses to a minimum.

</details>

<details id="question-4-virtual-machines-as-saas">
<summary><strong>Question 4 - Virtual machines as SaaS</strong></summary>

This item shares its setup with other questions. Each one proposes a different solution. Decide whether this solution meets the goal.

You are tasked with deploying Azure virtual machines for your company.

You need to make use of the appropriate cloud deployment solution.

Solution: You should make use of Software as a Service (SaaS).

Does the solution meet the goal?

- A. Yes
- B. No

</details>

<details id="answer-4">
<summary><strong>Answer 4</strong></summary>

B. No.

SaaS is a finished application you use, such as Microsoft 365. Deploying virtual machines means you rent the infrastructure and manage the OS, which is Infrastructure as a Service.

</details>

<details id="question-5-virtual-machines-as-paas">
<summary><strong>Question 5 - Virtual machines as PaaS</strong></summary>

This item shares its setup with other questions. Each one proposes a different solution. Decide whether this solution meets the goal.

You are tasked with deploying Azure virtual machines for your company.

You need to make use of the appropriate cloud deployment solution.

Solution: You should make use of Platform as a Service (PaaS).

Does the solution meet the goal?

- A. Yes
- B. No

</details>

<details id="answer-5">
<summary><strong>Answer 5</strong></summary>

B. No.

PaaS supplies the runtime and hides the virtual machines. A requirement to deploy virtual machines is Infrastructure as a Service, where you manage the operating system.

</details>

<details id="question-6-virtual-machines-as-iaas">
<summary><strong>Question 6 - Virtual machines as IaaS</strong></summary>

This item shares its setup with other questions. Each one proposes a different solution. Decide whether this solution meets the goal.

You are tasked with deploying Azure virtual machines for your company.

You need to make use of the appropriate cloud deployment solution.

Solution: You should make use of Infrastructure as a Service (IaaS).

Does the solution meet the goal?

- A. Yes
- B. No

</details>

<details id="answer-6">
<summary><strong>Answer 6</strong></summary>

A. Yes.

Infrastructure as a Service is the model for Azure virtual machines. You manage the operating system and the apps. Microsoft manages the hardware.

</details>

<details id="question-7-web-tier-for-ten-apps">
<summary><strong>Question 7 - Web tier for ten apps</strong></summary>

Your developers have created 10 web applications that must be hosted on Azure.

You need to determine which Azure web tier plan to host the web apps. The web tier plan must meet the following requirements:

- The web apps will use custom domains.
- The web apps each require 10 GB of storage.
- The web apps must each run in dedicated compute instances.
- Load balancing between instances must be included.
- Costs must be minimized.

Which web tier plan should you use?

- A. Standard
- B. Basic
- C. Free
- D. Shared

</details>

<details id="answer-7">
<summary><strong>Answer 7</strong></summary>

A. Standard.

Free and Shared use shared compute and 1 GB of storage, so they miss the dedicated-instance and 10 GB requirements. Basic has dedicated instances, custom domains, and 10 GB, but on the tier table this question uses, load balancing starts at Standard. Standard is the cheapest tier that meets every requirement.

</details>

<details id="question-8-one-directory-or-several">
<summary><strong>Question 8 - One directory or several</strong></summary>

This item shares its setup with other questions. Each one proposes a different solution. Decide whether this solution meets the goal.

You are planning to migrate a company to Azure. Each of the company's numerous divisions will have an administrator in place to manage the Azure resources used by their respective division.

You want the Azure deployment to be segmented for the divisions, while keeping administrative effort to a minimum.

Solution: You plan to make use of several Azure Active Directory (Azure AD) directories.

Does the solution meet the goal?

- A. Yes
- B. No

</details>

<details id="answer-8">
<summary><strong>Answer 8</strong></summary>

B. No.

A separate directory is a separate tenant. Each one has its own identities, and that raises administrative effort. Segment the divisions with separate subscriptions in one directory, and give each division admin access to its own subscription.

</details>

<details id="question-9-web-tier-for-the-miami-site">
<summary><strong>Question 9 - Web tier for the Miami site</strong></summary>

Your developers have created a portal web app for users in the Miami branch office. The web app will be publicly accessible and used by the Miami users to retrieve customer and product information. The web app is currently running in an on-premises test environment.

You plan to host the web app on Azure.

You need to determine which Azure web tier plan to host the web app. The web tier plan must meet the following requirements:

- The website will use the miami.weyland.com URL.
- The website will be deployed to two instances.
- SSL support must be included.
- The website requires 12 GB of storage.
- Costs must be minimized.

Which web tier plan should you use?

- A. Standard
- B. Basic
- C. Free
- D. Shared

</details>

<details id="answer-9">
<summary><strong>Answer 9</strong></summary>

A. Standard.

Free has no custom domain and 1 GB of storage. Shared has a custom domain but still 1 GB and no custom SSL. Basic adds custom domains, SSL, and scale-out, but its storage limit is 10 GB, and this site needs 12 GB. Standard is the cheapest tier with 50 GB, SSL, a custom domain, and more than one instance.

</details>

<details id="question-10-pay-as-you-go-expenditure-model">
<summary><strong>Question 10 - Pay-as-you-go expenditure model</strong></summary>

This item shares its setup with other questions. Each one proposes a different solution. Decide whether this solution meets the goal.

Your company is planning to migrate all their virtual machines to an Azure pay-as-you-go subscription. The virtual machines are currently hosted on the Hyper-V hosts in a data center.

You are required to make sure that the intended Azure solution uses the correct expenditure model.

Solution: You should recommend the use of the elastic expenditure model.

Does the solution meet the goal?

- A. Yes
- B. No

</details>

<details id="answer-10">
<summary><strong>Answer 10</strong></summary>

B. No.

Pay-as-you-go is an operational expenditure (OpEx) model: you rent capacity and pay for what you use. "Elastic expenditure" is not an Azure expenditure model. Elasticity describes scaling, not how the spend is classified.

</details>
