# AWS Certified Solutions Architect Associate (SAA-C03) Course by Neal Davis

## [COURSE](https://www.udemy.com/course/aws-certified-solutions-architect-associate-hands-on/)

## Introduction

The **AWS Certified Solutions Architect Associate (SAA-C03)** course by Neal Davis (Digital Cloud Training) is a theory-plus-hands-on path to the associate exam. Study **in order**: watch theory, then complete **HOL** labs in your own AWS account, then use end-of-section architecture patterns, exam crams, quizzes, and cheat sheets.

Use this file as the table of contents. Open a lecture page when you are ready to study that video.
